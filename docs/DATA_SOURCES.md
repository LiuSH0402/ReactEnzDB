# 数据来源与贡献范围

ReactEnzDB继承并组织已有生化资源和文献信息。来源内容不能冒称本平台新增实验或独立验证。实际来源版本、记录级对应及再分发范围以相应输入和数据发布说明为准。

本地代码/登记中涉及的主要来源包括：RDBSB基础反应与酶记录，UniProt蛋白身份与注释，ChEBI/PubChem化学身份信息，Rhea反应对应，BRENDA和SABIO-RK动力学/实验信息，InterPro/Pfam域，PDB和AlphaFold结构对应，MetaNetX交叉引用，M-CSA机制，以及原始论文。KEGG、MetaCyc/BioCyc等来源还受实际公开范围与条款限制；代码中的链接或标识不意味着整份来源数据库已在本仓库中再发布。

- RDBSB：https://www.biosino.org/rdbsb/
- UniProt：https://www.uniprot.org/
- ChEBI：https://www.ebi.ac.uk/chebi/
- PubChem：https://pubchem.ncbi.nlm.nih.gov/
- Rhea：https://www.rhea-db.org/
- BRENDA：https://www.brenda-enzymes.org/
- SABIO-RK：https://sabiork.h-its.org/
- InterPro：https://www.ebi.ac.uk/interpro/
- PDB：https://www.wwpdb.org/
- AlphaFold DB：https://alphafold.ebi.ac.uk/
- MetaNetX：https://www.metanetx.org/
- M-CSA：https://www.ebi.ac.uk/thornton-srv/m-csa/

以上为来源入口清单，不是逐字段授权证明。最终论文还需引用实际使用的资源论文、数据版本和原始实验；来源版本未知时应标未记录，不能填一个猜测版本。

本平台可主张的整理贡献需由具体结果证明：化学身份/方向统一，保守蛋白标识与坐标对应，反应—酶—证据连接，公开范围筛选，工具输出连接和证据导航。既有来源条目与新增整理结果应可区分。

本代码包没有公开采集器，但保留离线解析和必要来源说明；没有删除原始数据来源来掩盖继承关系。数据自身的许可、源码许可和第三方模型许可分别适用。
