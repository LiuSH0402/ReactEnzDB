# Data sources

ReactEnzDB organizes information from biochemical resources and the primary literature. Source annotations and experimental findings retain their original attribution. Resource versions, record-level mappings and redistribution scope are defined by the corresponding inputs and release metadata.

| Resource | Information used or referenced |
| --- | --- |
| [RDBSB](https://www.biosino.org/rdbsb/) | Base reaction and enzyme records |
| [UniProt](https://www.uniprot.org/) | Protein identifiers and annotations |
| [ChEBI](https://www.ebi.ac.uk/chebi/) and [PubChem](https://pubchem.ncbi.nlm.nih.gov/) | Chemical identities and structures |
| [Rhea](https://www.rhea-db.org/) | Reaction mappings |
| [BRENDA](https://www.brenda-enzymes.org/) and [SABIO-RK](https://sabiork.h-its.org/) | Kinetic and assay information |
| [InterPro](https://www.ebi.ac.uk/interpro/) / Pfam | Protein domains |
| [PDB](https://www.wwpdb.org/) and [AlphaFold DB](https://alphafold.ebi.ac.uk/) | Structural cross-references |
| [MetaNetX](https://www.metanetx.org/) | Cross-references |
| [M-CSA](https://www.ebi.ac.uk/thornton-srv/m-csa/) | Catalytic mechanisms |
| Primary publications | Experimental evidence and contextual annotations |

KEGG and MetaCyc/BioCyc references are subject to the applicable release scope and source terms. A link or identifier in the code does not indicate redistribution of the complete source database.

ReactEnzDB processing includes chemical identity and direction normalization, conservative protein mapping, reaction–enzyme–evidence links, release filtering and tool-output integration. These processing results should be distinguished from inherited source content when reporting contributions.

Cite the resources, versions and original experimental publications used in an analysis. Code, data and upstream model resources retain their respective licensing terms; see [Third-party notices](../THIRD_PARTY_NOTICES.md).
